How Mail Tracking Works

Cloud Server Ready

Your MailTracker server is deployed and ready to record real-time opens globally.

1

1x1 Invisible Pixel

An HTML <img> tag pointing to your cloud server is embedded inside your email message.

2

Recipient Opens Email

The recipient's mail client (Gmail/Outlook) loads HTML and fetches the image from your cloud server.

3

Server Logs Event & Serves Image

Your server records timestamp, IP, and User-Agent, then returns a transparent PNG with anti-caching headers.

Pro Tips & Caveats:
  • Image Blocking: If recipient blocks remote images, open won't register until enabled.
  • Gmail Proxy: Gmail proxies images via Google servers to protect recipient privacy.
  • Anti-Caching: Headers force email clients to send new requests on every re-open.

How to Send Tracked Emails in Gmail

Server Status: Live Cloud Server

Your server is public and actively tracking email opens globally.

Step 1: Create & Copy Email

  1. Click "+ Create Tracked Email" in MailTracker.
  2. Type your email text or HTML content.
  3. Click "Copy for Gmail (Direct Paste)".

Step 2: Paste directly into Gmail

  1. Open Gmail (mail.google.com) and click Compose.
  2. Type the Subject and Recipient email address.
  3. Click inside the main message body box and press Ctrl + V (or Cmd + V).
  4. Your formatted message including the invisible tracking pixel will be pasted directly into Gmail!
  5. Click Send!
